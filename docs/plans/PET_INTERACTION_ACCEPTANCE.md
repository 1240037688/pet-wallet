# 宠物交互与智能泡泡升级验收报告（2026-10-08）

## 一、需求实现详情

### 1. 宠物自主闲时与任务后冒泡
- **当前会话供应商额度感知**：
  - 会话网关事件（`SESSION_INFO`）动态绑定当前会话的 `provider` 与 `model`。
  - 自动匹配当前会话使用的供应商（如 Codex、DeepSeek），优先播报该供应商的订阅与剩余额度（如 `Codex 5h剩75% · 周剩68%`）；
  - 若当前会话无对应独立订阅接口，智能回退为已配置订阅汇总或今日总花费。
- **任务完成自动反馈**：
  - 任务结束（`TASK_COMPLETED`）后自动展示完成气泡，并带出最新的额度或消费数据，TTL 6 秒自动淡出。
- **闲时定时唤醒（Idle Timer）**：
  - 用户无操作空闲达 6~8 分钟时，自动轻量冒泡问候或提醒当前额度状态，不霸屏打扰（TTL 7 秒自动消失）。

### 2. 连续点击多态阶梯交互（不停点击说的话不同）
- **1~3 连击（信息与管家问候）**：
  - 点击 1：多套温馨问候语随机轮换（不重样）；
  - 点击 2：展示当前会话供应商额度（Session 5h / Weekly 周配额）；
  - 点击 3：展示今日账本消费与轮次；
- **4~7 连击（调皮/吐槽话术池）**：
  - 触发趣味吐槽（“戳我好多次啦！有在认真写代码吗～”、“钱包管家正在盯着你的余额呢，别摸鱼～”等 5+ 句随机不重复）；
- **8+ 连击（高阶彩蛋）**：
  - 触发「⚡ 达成神级连击！代码无 Bug Buff」彩蛋。

### 3. 泡泡自身交互升级
- **单击泡泡**：直接切换下一页话术。
- **双击泡泡**：直接唤起并打开「宠物 Wallet」大面板。
- **鼠标悬停**：手型指针（`pointer`），反馈清晰直观。
